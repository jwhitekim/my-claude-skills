## 작업 폴더 밖을 건드리기 전에 확인한다 (절대 규칙)

세션의 작업 디렉터리 밖에 있는 파일을 **처음** 고치려 할 때는 편집하기 전에 멈추고 사용자에게 확인한다.

- 확인 없이 밖으로 나가지 않는다. 사용자가 그 프로젝트의 화면 캡처를 보내거나 그 경로를 말했다는 것만으로 편집 허가로 보지 않는다.
- 확인할 때는 **어느 프로젝트의 어느 파일을 고치려 하는지 경로로 밝힌다.**
- 한 번 허가를 받으면 **그 프로젝트 안에서는** 다시 묻지 않는다. 또 다른 프로젝트로 넘어갈 때 다시 확인한다.
- **세션 밖에서 작업하는 동안에는 매 응답마다 계속 표시한다.** 한 번 알리고 마는 것이 아니라, 그 작업이 끝날 때까지 **모든 답변의 맨 윗줄에** 아래 경고를 붙인다. 세션 폴더로 돌아오면 뗀다.

  터미널 답변은 마크다운으로 렌더되어 글자색 지정 문법이 없다. **빨강은 🔴 로 낸다.**

  ```
  🔴🔴🔴 **세션 밖 폴더에서 작업중** 🔴🔴🔴
  > **`D:\...\고치는-폴더`** ← 지금 이 폴더를 고치고 있습니다. 여긴 `<세션폴더>` 세션입니다.

  ---
  ```

  - 경로는 **실제 고치는 폴더**로 채운다. 줄이지 말고 전체 경로를 적는다.
  - 답변이 짧든 길든 **매번** 맨 위에 붙인다. 중간에 빼먹지 않는다.
  - 작업이 끝나 세션 폴더로 돌아오면 배너를 떼고, **"세션 폴더로 복귀"** 라고 한 줄 알린다.
- 밖에서 작업하기로 했으면 **첫 편집 전에 되돌릴 수단을 만든다.** git 저장소면 상태를 확인하고, 아니면 대상 폴더를 복사해 둔 뒤 그 위치를 알린다.

메모리 폴더(`~/.claude/projects/<프로젝트>/memory/`) 저장은 세션 밖 작업으로 보지 않는다. 경로는 작업 폴더 밖이지만 프로젝트마다 따로 있는 그 프로젝트의 기록이다. 확인을 묻지 않고 배너도 붙이지 않는다.

읽기만 하는 것(Read·Grep·Glob)은 확인 없이 해도 된다. 이 규칙은 파일을 **바꾸는** 경우에만 적용한다.
