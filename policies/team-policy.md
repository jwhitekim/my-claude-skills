## 팀장과 직원의 역할

팀장은 메인 Claude, 직원은 Agent 도구로 띄우는 하위 에이전트를 뜻한다.

직원 모델은 settings.json의 환경변수 `CLAUDE_CODE_SUBAGENT_MODEL=haiku`, `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1`로 Haiku에 고정된다. 직원을 띄울 때 모델을 따로 지정하지 않는다.

- 메인 추론은 팀장이 맡는다. 설계, 원인 분석, 코드 작성과 수정 판단, 결과 검증, 최종 결론과 사용자 보고는 팀장이 직접 한다.

- 직원에게는 판단이 덜 필요한 일을 맡긴다. 정해진 명령 실행, 오래 걸리는 호출과 대기, 커밋·푸시, 넓은 범위의 파일 탐색과 자료 수집, 절차가 정해진 반복 작업이 이에 해당한다.

- 위임은 팀장이 핵심 판단에 집중하는 데 도움이 될 때 쓴다. 짧은 명령 한두 번처럼 설명하고 결과를 받는 비용이 더 크면 팀장이 바로 처리해도 된다.

- 직원에게는 목적, 정확한 명령이나 절차, 작업 경로와 대상 파일, 허용된 변경 범위, 돌려줄 결과, 멈출 조건을 구체적으로 알려 준다.

- 이미 커밋된 상태, 충돌, 예상과 다른 출력처럼 새 판단이 필요한 상황을 만나면 임의로 해결하거나 범위를 넓히지 말고 멈춰 보고하게 한다. 다음 조치는 팀장이 정한다.

- 직원이 다루는 파일은 작업과 결과 확인이 끝날 때까지 팀장이나 다른 직원이 동시에 수정하지 않는다. 변경이 필요하면 먼저 해당 작업을 멈추고 조율한다.

- Codex CLI 호출 등을 맡길 때는 실행과 원문 전달을 요청한다. 직원의 해석이나 요약이 원문과 실행 상태를 대신하지 않게 한다.

- 직원의 완료 보고나 검증 의견만으로 성공을 확정하지 않는다. 팀장이 출력과 변경 내용을 확인하고 필요한 검증을 직접 수행한다. 추가 검토가 필요하면 Codex 스킬을 활용한다.

- 직원 결과를 받은 뒤에는 팀장이 확인한 결과를 사용자에게 알린다. 특히 검증 결과는 내부 확인만 하고 넘기지 않으며, 확인한 내용과 남은 문제를 요약이나 표로 전달한다.
